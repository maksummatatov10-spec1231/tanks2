# Awesome Tanks 2.0 — мод на оригинальную игру

Неофициальный мод **2.0** для HTML5-версии **Awesome Tanks 2** (Phaser 2.6.2 + Box2D).
Мод не заменяет игру, а достраивает её: подключается перед её скриптом, перехватывает
данные (`AT.SETTINGS`, `AT.LEVELS`) и дописывает своё поведение поверх.

**В релизе нет ни одного файла игры**: только собственный код, собственные карты
и собственные числа. Игра и её ассеты принадлежат правообладателям.

## Что даёт 2.0

| Блок | Что нового |
|---|---|
| **Меню** | новый экран-хаб `AT2Hub`: две кампании сеткой уровней с лучшими очками, магазин новых стволов, магазин модификаторов, сложность, справка. Кнопка *play* в ванильных меню ведёт в хаб |
| **Физика** | инерция разгона и торможения вместо мгновенной скорости, мягкий отскок от стен, спокойнее тряска камеры, демпфирование корпуса |
| **Карты** | 15 новых собственных карт (уровни 16–30) **в дополнение** к 15 оригинальным; у новых карт свои имена, стили и лучшие очки в сохранении |
| **Оружие** | 6 новых стволов помимо ванильных: «Шквал», «Плазмаган», «Осколочница», «Пронзатель», «Рой», «Тесла» (клавиши `Z X C V B N`) |
| **Модификаторы** | 20 уникальных, покупаются за **ядра** (вторая валюта): ноуклип на 5 секунд сквозь стены и пули, щит, рывок, хронометр, ядерный залп, блинк, ударная волна, форсаж, берсерк, гусеницы «Вихрь», шипованные колёса, колёса «Пантера», собиратель, вампиризм, композитная броня, боезапас 2.0, сканер, магнит, призрак, детонатор |
| **Экономика** | ядра падают за убийства, боссов и зачистку уровней; щедрее патронные наборы, дешевле вход в пушки, боезапас частично восстанавливается после боя |
| **В бою** | счётчик ядер в HUD, быстрый выбор новых стволов, панель мода по `M` со списком купленного и перезарядок |

Ядра (`Я` в интерфейсе) — вторая валюта: деньги покупают стволы и ванильные
апгрейды, ядра — модификаторы. Всё сохраняется в том же сохранении игры
(`localStorage["AWESOME-TANKS-2"]`, раздел `mod`).

## Быстрый запуск (одна команда)

Готовый архив для пользователя собирается скриптом `tools/make-release.py`
(в git он не попадает — каталог `release/` игнорируется):

```bash
python3 tools/make-release.py        # release/awesome-tanks-2.0-mod.zip — только мод
```

Внутри архива нет ни одного файла игры — только мод, документация и `start.py`.
Игрок распаковывает архив **в папку со своей копией игры** и запускает:

```bash
python3 start.py          # Windows: start.bat или py -3 start.py
```

`start.py` сам находит копию игры (рядом, в `game/`, у соседей, в «Загрузках»),
копирует `mods/`, подключает их в `index.html` (с бэкапом), поднимает локальный
сервер и открывает игру в браузере. Полезные ключи: `--game <путь>`,
`--port 9000`, `--check` (только установка), `--uninstall` (полный откат),
`--no-browser`, `--host 0.0.0.0`.

## Установка вручную

Нужна своя копия HTML5-версии игры (этот мод её не содержит и не скачивает).

```bash
# 1) поставить в копию игры: скопирует mods/ и подключит их в index.html
node tools/at2-mod-installer.js --game "/путь/к/копии/игры"

# варианты
node tools/at2-mod-installer.js --game "..." --dry-run          # посмотреть план
node tools/at2-mod-installer.js --game "..." --packs at2-core,at2-ui   # часть паков
node tools/at2-mod-installer.js --game "..." --uninstall        # откат в одну команду
```

Установщик делает бэкап `index.html.at2mod.bak` и вставляет блок `<script>` между
маркерами `AT2MOD:BEGIN/END` — откат возвращает файл байт-в-байт.

Альтернативы:

* **Юзерскрипт** `mods/userscript/awesome-tanks-2-modkit.user.js` — для Tampermonkey,
  если игра открывается прямо на сайте-портале (файлы мода подтягиваются из репозитория).
* **Вручную** — подключить `mods/mod-loader.js` и паки перед `<script src="awesome_tanks_2.js">`.

## Запуск

```bash
python3 -m http.server 8080     # открыть http://localhost:8080/
```

Только через http-сервер: при `file://` браузер блокирует JSON-атласы и игра
застревает на загрузке. Открывать `index.html` (чистая локальная версия), а не
`(index)` — последний тянет рекламный SDK и логотип портала.

## Консоль

```js
MOD.help();        // все команды
MOD.help2();       // что в моде: ядра, модификаторы, стволы
MOD.addCores(200); // вторая валюта
MOD.arsenal.list(); MOD.mods.list();
MOD.unlockAll(); MOD.maxWeapons(5); MOD.maxUpgrades(); MOD.god(true);
MOD.toHub();       // открыть хаб 2.0
```

## Структура репозитория

| Путь | Что это |
|---|---|
| `index.html` | локальный запуск игры + подключение мод-кита (без рекламы и аналитики) |
| `(index)` | оригинальная страница портала (историческая копия, не для запуска) |
| `awesome_tanks_2.js` | сама игра (Phaser + Box2D + код игры в одном файле) |
| `mods/mod-loader.js` | ядро мод-кита: перехват данных, реестры, вторая валюта, `MOD.*` |
| `mods/packs/at2-core.js` | физика 2.0, ядра, экономика, события уровней |
| `mods/packs/at2-campaign.js` | 15 новых карт (генерируются `tools/build-packs.js`) |
| `mods/packs/at2-weapons.js` | 6 новых стволов + магазин арсенала |
| `mods/packs/at2-modifiers.js` | 20 модификаторов + их эффекты и клавиши |
| `mods/packs/at2-ui.js` | хаб-меню 2.0, HUD-счётчик ядер, панель мода |
| `mods/packs/demo-pack.js` | старый демо-пак из 2.0-кита (пример пака) |
| `tools/at2-mod-installer.js` | установщик/деинсталлятор |
| `tools/gen-campaign.js`, `tools/lib/validate-maps.js` | генератор и валидатор карт |
| `tools/build-packs.js` | сборка `at2-campaign.js` из `tools/campaign-data.json` |
| `tools/test-*.js`, `tools/test-installer.sh` | тесты (61 + 42 + 17 проверок) |
| `ANALYSIS.md` | разбор игры: математика, форматы, точки расширения |
| `PUBLISHING.md` | как публиковать мод, ничего не нарушая |
| `images/ sounds/ scripts/ styles/ fonts/` | ассеты игры (в `.gitignore`, в Git не коммитятся) |

## Тесты

```bash
npm i jsdom
node tools/test-modkit.js      # ядро и формат паков       — 42 проверки
node tools/test-2.0.js         # паки 2.0 целиком         — 61 проверка
bash tools/test-installer.sh   # установка/откат          — 17 проверок
```

Тесты 2.0 поднимают jsdom-окружение, подключают ядро и все пять паков,
эмулируют публикацию `AT.SETTINGS`/`AT.LEVELS` игрой, покупки, дроп ядер,
инерцию движения и переходы меню, а новые карты прогоняют через валидатор.
