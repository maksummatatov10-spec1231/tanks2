# Моддинг Awesome Tanks 2 — практикум

Всё, что описано ниже, проверяется на локальной сборке из этого репозитория
(`index.html` + `mods/mod-loader.js`). Разбор игры — в `../ANALYSIS.md`.

---

## 0. Как устроен мод-лоадер

Игра хранит свои данные в объекте `window.AT`, который создаётся в HTML:

```html
<script> var AT = { SITE_LOCK_TARGET: '' }; </script>
<script src="mods/mod-loader.js"></script>   <!-- перехватчик -->
<script src="awesome_tanks_2.js"></script>   <!-- игра -->
```

`mod-loader.js` вешает на `AT` геттеры/сеттеры для `SETTINGS` и `LEVELS`.
Когда игра делает `window.AT.SETTINGS = {...}` или `window.AT.LEVELS = [...]`,
управление сначала попадает в ваш колбэк — можно править настоящие данные игры.
После загрузки игры лоадер применяет блок `CONFIG` (деньги, уровни, оружие,
бессмертие, заглушка рекламы) и публикует рантайм-API `window.MOD`.

Откройте консоль браузера и введите `MOD.help()` — получите список команд.

## 1. Деньги, уровни, сложность

```js
MOD.money(999999);      // поставить точную сумму
MOD.addMoney(50000);    // добавить
MOD.unlockAll();        // открыть все 15 уровней
MOD.setLevels(7);       // открыть 7 уровней
MOD.setDifficulty(2);   // 0 легко, 1 средне, 2 сложно
```

Без лоадера, чистым localStorage (DevTools → Application → Local Storage →
`AWESOME-TANKS-2`): поменяйте `game.money`, `game.levels`, `game.difficulty`.

---

## 2. Оружие и апгрейды

```js
MOD.maxWeapons(5);      // все 10 пушек на 5 уровень + патроны по максимуму
MOD.maxWeapons(0);      // все пушки куплены, но без прокачки
MOD.maxUpgrades();      // броня/башня/обзор/скорость на максимум
MOD.refillAmmo();       // только патроны
MOD.ammo("rockets", 45);// патроны конкретной пушки
```

Внутри это просто поля профиля: `minigunLevel … minesLevel` (−1 = оружие не
куплено, 0..5 — уровень) и `XxxAmmo`. Список ключей — в `ANALYSIS.md`, раздел 7.
Изменения подхватываются при входе на уровень (новый танк собирается из профиля),
поэтому после команд перезайдите в уровень.

## 3. Правка цен и лимитов (без редактирования игры)

Положите в `mod-loader.js` в поле `patchSettings`:

```js
patchSettings: function (S) {
    // корпус, башня, обзор, скорость: [ур.1, ур.2, ур.3, ур.4, ур.5]
    S.PRICES.armor  = [200, 400, 800, 1600, 3200];
    S.PRICES.speed  = [100, 200, 300, 400, 500];

    // оружие: [цена открытия, цена ур.1 … ур.5]
    S.PRICES.rockets = [1000, 500, 600, 700, 800, 900];

    // патроны
    S.AMMO_PRICES.shotgun = 10;    // цена порции
    S.AMMO_AMOUNT.shotgun = 100;   // сколько в порции
    S.AMMO_LIMITS.shotgun = 9999;  // максимум в обойме

    // достижения — сколько чего нужно сделать
    S.ACHIEVEMENTS_LIMITS.destroyer = 5;   // было 80
}
```

Полный список полей — `AT.SETTINGS` в `awesome_tanks_2.js` (стр. 20017).

## 4. Свои уровни

Формат карты: `[ "Имя", "террейн", "строка", "строка", … ]`, где территория —
`grass` / `snow` / `desert`. Легенда символов — `ANALYSIS.md`, раздел 6.

```js
patchLevels: function (levels) {
    // Полностью заменить 1-й уровень
    levels[0] = [
        "Крепость", "snow",
        "███████████████████",
        "█ ☻        ○     █",
        "█   ##  ▒▒▒  ##  █",
        "█   #    □    #   █",
        "█   ##  ▒▒▒  ##  █",
        "█        ○        █",
        "█  2   4   m   5  █",
        "█                 █",
        "███████████████████"
    ];
}
```

Правила:

* ровно один `☻` (точка старта игрока);
* хотя бы один враг/спавнер — победа наступает, когда живых врагов не осталось;
* рамка из `█` по периметру (иначе камера и туман ведут себя странно);
* ширина карты берётся из первой строки — лучше держать все строки одной длины;
* незнакомый символ превращается в траву, игра не падает.

Ограничения UI: меню уровней рисует жёстко 15 кнопок
(`for (var t = 0; t < 15; t++)`) и берёт иконки из атласа `menu/levels.png`.
Поэтому «свои 15 уровней» — легко, «16-й уровень кампании» — уже нужна правка
меню и атласа. Тестовые карты при этом доступны напрямую:

```js
AT.game.state.start("Level16");  // Fog Test
AT.game.state.start("Level34");  // Bosses: Shotgun
AT.game.state.start("Level41");  // Performance Test 1
```

## 5. Реклама, слежка, логотип

* `CONFIG.blockAds = true` (по умолчанию) — подменяет `window.showBanner` пустышкой.
* `cmgGameEvent` — аналитика CoolMath, в локальном `index.html` тоже заглушка.
* Оригинальная `(index)` тянет `https://m.igroutka.ru/ni3/sdk.js`,
  их `script.js`, логотип-ссылку и full-screen `#game_lock`. Открывайте
  `index.html`, а не `(index)`, если не хотите ни того, ни другого.

## 6. Что ещё можно покрутить

| Хочу | Где |
|---|---|
| Урон/темп оружия | массивы в конструкторе `Player` (`awesome_tanks_2.js`, стр. 22405–22540) |
| Здоровье/скорость/обзор врагов | конструкторы танков (стр. 21985+) |
| Поведение ИИ | `window.AT.ai.*` (Idle/Patrol/Chase/Attack) |
| Цена монеты | стр. 23914 — формула `(номер<11?12:15)*(1+0.8567*индекс)*сложность` |
| Порог/формула очков | `points` в классах танков и спавнеров |
| Порядок волн спавнера | `spawnTypes` (стр. 22310+) |
| Звук/музыка по умолчанию | `profile.DEFAULT.game.sound/music` |
| Заставки/скорость загрузки | `MenuLoading.loadAssets`, `setTimeout(..., 500)` |
| Бессмертие/читерские режимы | `MOD.god(true)`, `MOD.killAll()` |

## 7. Полезно знать

* Сохранение — ключ `AWESOME-TANKS-2` в localStorage. Всё правится и из кода,
  и руками. Бэкап делается копированием строки из DevTools.
* Не запускайте игру через `file://` — атласы грузятся XHR'ом, нужен http.
* Если после правок игра «застряла» на загрузке — откройте консоль: скорее всего
  не хватает файла ассета (см. пути `images/…` в `MenuLoading.loadAssets`).
* `(index)` — оригинальная страница, оставлена для истории; `index.html` — рабочая
  локальная версия.
